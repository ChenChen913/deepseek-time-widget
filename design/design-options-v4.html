推荐 PICK

01 示波器 —— 它是这一版里唯一把「峰谷」做成连续函数的方案。别的方案都是离散的块或柱，只有它画出了真正的波：上升、平台、下降、回落。你甚至能从曲线的坡度判断「离切换还有多久」。深色屏 + 网格 + 一条发光曲线，是六者中最像"仪器读数"的一台。

落地成本可控：曲线用 Path + PolyLineSegment（96 个采样点，代码生成一次即可，不用手写）。当前时刻的圆点按 t/24 取同一组采样点定位。不用动画，只有秒位每秒刷新一次文字。

备选：想让人一眼笑出来就选 05 双峰——两座尖峰摆在横条右侧，峰顶标「峰」、谷底标「谷」，是最直白的一张梗图；03 K 线则是把"倍率"这个金融语义吃透的做法，红涨绿跌，股民一看就懂。

关于梗：「梁文峰 / 梁文谷」是网友对 DeepSeek 创始人梁文锋的戏称，取自高峰/低谷的谐音双关，非官方叫法。本页仅作设计练习，不涉及任何官方立场。

关于规则：高峰 = 周一至周五（不含中国法定节假日）09:00–12:00、14:00–18:00，1.0×；其余全部时间 0.5×。周末即使遇调休上班日也按官网字面规则算空闲。只有两种价格状态。

关于数据：所有时间为静态 mock 数据，时钟按各自基准时间实时走动（秒位每秒 +1），倒计时保持静态以对齐 mock 值。真实实现中倒计时按北京时间计算，与系统时区无关。

三个版本：v2 液态玻璃 / v3 仪器面板 / v4 峰谷梗。三个文件平行存在，可并排比对。
