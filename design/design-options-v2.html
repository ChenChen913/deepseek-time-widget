DeepSeek 时段挂件 / 6 个 UI 方案

常驻 Windows 桌面右下角的计费时段提示小挂件。视觉全部围绕一个判断：现在是高峰还是空闲。其余信息一律压低对比度，让状态色成为唯一焦点。

实际尺寸 316 × 180 DIP 展示放大 1.15× 目标 Windows 11 · 125% 缩放 单文件 · 离线可用 字体 Microsoft YaHei UI / Segoe UI Variable

使用说明

四种状态全覆盖每个方案都并排给出高峰、工作日空闲、周末、法定节假日四态，全部使用同一套 mock 数据，可直接横向比对。
极端文案压力测试场景 B 专门放「10月1日 · 国庆节 · 数据待更新」+「6天 23:00:00」，验证日期行不溢出、倒计时不挤压时钟。
两种壁纸场景 A 深色壁纸、场景 B 浅色壁纸，玻璃的模糊、折射边、内高光、状态光晕都必须在这两种底色下同时成立。
悬停无浮层鼠标移上去只有 3px 上浮和流光扫过，没有任何 tooltip 或文字浮层——所有信息常驻，进度条纯装饰。
边缘留白挂件四周预留 10px 无交互区，供拖动、右键与置顶按钮避让，避免贴边时误触；内容区不做任何弹出式交互。
高峰时段 · 1.0× · 周一至周五 09:00–12:00 / 14:00–18:00 空闲时段 · 0.5× · 其余全部时间 周末 / 法定节假日 → 全天 0.5×（调休上班日也按周末算） 数据待更新 · 节假日数据缺失时的兜底提示

我的推荐 PRIMARY

01 深空琥珀 —— 唯一一个在深色壁纸、浅色壁纸、彩色壁纸下都不需要妥协的方案。深色半透明底自带一层"保底对比度"，所以状态色可以做到很低的饱和度也不糊；状态光晕从右上角渗出，是唯一让"玻璃"和"状态"发生关系的地方——光晕颜色即状态色，不看字也知道现在贵不贵。

落地成本也最合理：Win11 的 AcrylicBrush 直接对应它的底，流光是一条 LinearGradientBrush 加 TranslateTransform，光晕是一条 RadialGradientBrush 加 Opacity 动画。三个动画都是 WPF 最便宜的属性动画，24 小时挂着也不烫。

备选：如果你更看重"一眼看清数字"而不是氛围，选 06 极简薄片——没有光晕、没有流光、没有颗粒，纯靠排版和 1px 细线，WPF 里几乎零成本，浅色壁纸上反而是六者中最清楚的。03 流光胶囊适合想贴任务栏横着放、且愿意接受 480px 宽度的场景。

关于数据：本页所有时间为静态 mock 数据，时钟按各自基准时间实时走动（秒位每秒 +1），倒计时保持静态以对齐 mock 值。真实实现中倒计时需按北京时间计算，与系统时区无关。

关于规则：高峰 = 周一至周五（不含中国法定节假日）09:00–12:00、14:00–18:00，1.0×；其余全部时间 0.5×。周末即使遇调休上班日也按官网字面规则算空闲。只有两种价格状态，不引入第三种。

关于 WPF：浏览器里的 backdrop-filter 在 WPF 中不存在。每个方案的降级路径 = 半透明渐变底 + 顶部 1px 内高光 + 底部内阴影 + 可选 BlurEffect。Win11 下优先用系统亚克力 / Mica，取不到再走降级，两条路径视觉差异控制在可接受范围内。
